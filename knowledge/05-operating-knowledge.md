# 05 — Operating Knowledge

Use this domain to define how work is performed safely and repeatably.

## Capture

- workflows, roles, and handoffs;
- tools, connectors, and authoritative data locations;
- current work state and unresolved questions;
- definitions of done and quality checks;
- approval, publishing, and spending boundaries;
- privacy, escalation, and failure handling;
- actions the agent may research, draft, recommend, prepare, or execute.

## Questions

- What inputs are required before work begins?
- Which source is authoritative when records conflict?
- Where must work stop for review?
- What can be reversed, and what would be difficult to recover?
- What state must be recorded so the next person or agent can continue?

## Current Knowledge

More operational context must not silently create more authority.
