# Knowledge Status

Use status to prevent a plausible observation from becoming an accidental rule.

| Status | Meaning |
| --- | --- |
| `unknown` | The required knowledge has not been supplied or verified |
| `raw` | Captured material that has not been contextualized or evaluated |
| `proposed` | A candidate interpretation, pattern, rule, or decision awaiting validation |
| `active` | Current human-approved guidance within a defined scope |
| `superseded` | Previously active guidance replaced by a later decision |
| `archived` | Retained for history but not expected to guide current work |

Status should be attached to the knowledge object, not inferred from the folder containing it.

When guidance changes, preserve the previous record, effective date, reason, and replacement.
