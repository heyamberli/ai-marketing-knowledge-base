# Contributing

Thank you for testing the AIMKT Marketing Knowledge Base Starter.

The most useful contribution at this stage is evidence from real marketing work: where the starter helped, where it failed, what the agent misunderstood, and what still required human judgment.

## Contributions We Welcome

Please open a GitHub Issue for:

- confusing instructions or behavior;
- feedback from a real marketing task;
- an anonymized example or failure case;
- a proposed workflow or feature.

Useful reports explain the task, what happened, what you expected, and why the difference mattered. You do not need to diagnose the solution.

## Privacy and Permission

Do not submit:

- credentials, tokens, or private links;
- identifiable customer, employee, founder, or client information;
- private analytics exports or campaign data;
- confidential strategies, conversations, contracts, or internal documents;
- material you do not have permission to share.

Use fictional or anonymized examples when possible. Remove sensitive values and identifying details before posting. Public GitHub Issues and pull requests should be treated as public information.

## Pull Requests

Changes to the core framework, templates, and agent behavior are reviewed selectively while the model is still evolving.

Before preparing a substantial pull request, open an Issue describing the problem and the evidence behind it. A discussion does not guarantee that a proposed change will be merged.

Small fixes to links, spelling, or unambiguous errors may be submitted directly. Please keep each pull request focused on one problem.

The project is not currently community-governed. Amber Li retains final editorial, framework, roadmap, and merge decisions.

## How Feedback Becomes Guidance

A report, example, or repeated behavior is evidence—not automatically a new rule.

```text
real-task feedback
    -> review and separate evidence from interpretation
    -> proposed learning
    -> test, narrow, approve, or reject
    -> optional framework update
```

This protects the starter from turning one person's context into universal guidance.
